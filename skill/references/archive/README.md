# Archive: the finished 153-post backlog runner

These references document the machinery that reviewed Wojtek's 153-post image backlog: the queue
(`queue.json`), verdict cards, card waits and holds, the runner and its watchdog, wakes, monitor
hops, settling and counting, closeout and disposition repair. That campaign is finished, so the
material is out of the loaded skill: nobody needs the queue recipes to draw a header.

Kept, not deleted, because the next campaign of this size will want them, and because the lessons
in them cost real renders.

What stayed in `skill/references/` instead: prompts, engines, style, text in images, library
records, check scripts, render selection and `paperclip-api.md`. If a file here is genuinely
useful for a live job, move it back with `git mv` and fix the links — do not link out of the
working set into this folder for a rule the current skill still enforces.
